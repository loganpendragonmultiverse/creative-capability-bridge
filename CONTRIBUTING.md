# Contributing

Thank you for improving Creative Capability Bridge. Open an issue or Discussion before large protocol or adapter changes so semantics and test evidence can be agreed first.

## Pull requests

1. Fork the repository and create a focused branch.
2. Add or update protocol and adapter tests for behavioral changes.
3. Run every command in `DEVELOPMENT.md`.
4. Update documentation, examples, and the changelog when public behavior changes.
5. Explain the capability semantics, application versions tested, source-preservation behavior, and unsupported cases in the pull request.

Pull requests require passing checks and maintainer review. New dependencies need a concrete benefit, license review, and security justification. AI-assisted contributions are allowed only when the contributor understands, tests, and takes responsibility for the submitted work.
