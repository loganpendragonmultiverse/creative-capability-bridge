# Support

- Use GitHub Discussions for setup questions, capability-model proposals, and adapter research.
- Use the structured bug form for reproducible defects with synthetic fixtures.
- Use private vulnerability reporting for security concerns.

Include the CCB version, Python version, operating system, selected adapter, native application version, command, sanitized plan, and complete error output. Maintainer support is best-effort; there is no guaranteed response time or compatibility with undocumented application releases.
