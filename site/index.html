One intent. Multiple creative tools.

Stop relearning the same operation.

Creative Capability Bridge defines a small, inspectable protocol for text and transforms, then helps you inspect documents, negotiate compatibility, package assets, and verify execution.

Protocol, not a skin

The shared layer stays small.

  1. DescribeBuild a versioned JSON plan with explicit targets and units.
  2. ValidateReject unsupported fields before an application is launched.
  3. TranslateUse a Blender background script or an Inkscape SVG adapter.
  4. PreserveWrite a separate output instead of silently changing the original.

New in 1.1

Carry evidence with the work.

  1. InspectDiscover IDs, text, fonts, and transforms without saving the source.
  2. NegotiateSee exact, approximate, or unsupported adapter results before retargeting.
  3. BundlePackage plans and assets with hashes, fallback fonts, and license notes.
  4. VerifyRecord output hashes and compare execution receipts across systems.
