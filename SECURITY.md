# Security policy

Security fixes are supported for the latest release.

Please use GitHub's private vulnerability-reporting feature instead of a public issue. Include the affected version, operating system, adapter, application version, minimal reproduction, impact, and any suggested mitigation. Do not include private documents or credentials.

Expected response targets are acknowledgment within seven days and a substantive assessment within fourteen days. These are goals, not guarantees.

CCB does not sandbox Blender, Inkscape, or supplied creative documents. Keep native applications current and review untrusted plans before execution. See `docs/security-model.md`.
